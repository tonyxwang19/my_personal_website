## Overview

This website is a quiet home for my work, notes, and visual collections. It keeps the original cosmic visual language while using a simple content structure that can grow over time.

## Content architecture

- Projects and writings are authored as Markdown.
- Photo sets are grouped as structured gallery entries.
- Every published entry receives its own static URL.
- Vercel rebuilds the site whenever new content is pushed to GitHub.

## Design principles

The interface stays deliberately minimal: a single navigation system, generous spacing, readable typography, and content that remains the focus.
